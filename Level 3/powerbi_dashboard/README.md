# Iris Dataset Power BI Dashboard

An interactive Power BI dashboard built using the Iris dataset.

## Project Overview

This project demonstrates data cleaning, exploratory analysis, data visualization, and dashboard development using Power BI.

## Tools Used

- Python
- Pandas
- Power BI
- DAX

## Dashboard Features

- KPI cards
- Species-level analysis
- Average sepal measurements
- Average petal measurements
- Interactive species filtering
- Visual comparison of Iris species

## Dataset

The Iris dataset was cleaned and prepared before being imported into Power BI.
